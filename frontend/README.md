# 🛡️ SecureScan Frontend

SecureScan is a modern React-based frontend for a Web Application Security Scanner. It provides an intuitive interface for user authentication, website security scanning, report visualization, and scan history management.

---

# 🚀 Features

* 🔐 User Registration
* 🔑 Secure User Login
* 👤 User Dashboard
* 🌐 Website Security Scanner
* 📊 Security Score Visualization
* 🟢 Safe / 🟡 Suspicious / 🔴 Malicious Status
* 📋 Scan History
* 📄 Download Security Reports
* 📱 Fully Responsive Design
* 🎨 Modern UI/UX

---

# 🛠️ Tech Stack

* React.js
* Vite
* React Router DOM
* Axios
* CSS3

# ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
cd securescan-frontend
```

Install dependencies:

```bash
npm install
```

---

# ▶️ Run the Application

```bash
npm run dev
```

Frontend runs at:

```text
http://localhost:5173
```

---

# 🔗 Backend Connection

Configure the API base URL in:

```text
src/services/api.js
```

Example:

```javascript
const api = axios.create({
  baseURL: "https://your-backend-url.onrender.com/api",
});
```
